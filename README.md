## fake-api

Este é um projeto de uma API simulada (fake) criado para aprender em sala de aula como funcionam as APIs, o formato de dados JSON e como hospedar um serviço online usando o GitHub.

---

## Principais objetivos de aprendizado:
* **O que é uma API:** Como os sistemas enviam e recebem dados.
* **Formato JSON:** Como organizar dados em formato de texto simples.
* **Hospedagem:** Como deixar a nossa API online e pública para qualquer um acessar.
